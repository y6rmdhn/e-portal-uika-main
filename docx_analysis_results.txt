[Heading] Line 265 (Heading 2): 2.2 Role-Based Access Control (RBAC)
Line 266 (): Role-Based Access Control (RBAC) adalah model kontrol akses yang mengatur hak akses pengguna berdasarkan peran (role) yang dimiliki, bukan berdasarkan identitas individu secara langsung. Sandhu et al. (1996) mendefinisikan RBAC sebagai kebijakan kontrol akses yang netral terhadap berbagai kebijakan keamanan yang ada dan cocok untuk berbagai domain aplikasi. Model ini distandarisasi oleh NIST dalam RBAC Reference Model yang mendefinisikan empat komponen inti: Users (pengguna), Roles (peran), Permissions (izin akses), dan Sessions (sesi aktif).

[Heading] Line 282 (Heading 2): 2.7 JSON Web Token (JWT)
Line 283 (): JSON Web Token (JWT) adalah standar terbuka (RFC 7519) yang mendefinisikan cara kompak dan mandiri untuk mentransmisikan informasi secara aman antara pihak-pihak sebagai objek JSON yang ditandatangani secara digital. JWT terdiri dari tiga bagian yang dipisahkan oleh titik: Header (algoritma dan tipe token), Payload (klaim atau data yang dibawa token), dan Signature (tanda tangan digital untuk memverifikasi keaslian token). Dalam sistem E-Portal UIKA, library tymon/jwt-auth digunakan untuk mengimplementasikan autentikasi stateless berbasis JWT pada backend Laravel, memungkinkan validasi identitas dan role pengguna tanpa perlu menyimpan sesi di server.

[Heading] Line 285 (Heading 2): 2.8 Black Box Testing
Line 286 (): Black Box Testing adalah metode pengujian perangkat lunak yang memverifikasi fungsionalitas sistem berdasarkan spesifikasi kebutuhan tanpa memperhatikan struktur internal kode program. Penguji memperlakukan sistem sebagai “kotak hitam” dan hanya berfokus pada input yang diberikan serta output yang dihasilkan. Metode ini efektif untuk memverifikasi apakah sistem berperilaku sesuai dengan kebutuhan yang telah ditetapkan, mendeteksi fitur yang hilang atau tidak berfungsi dengan benar, serta menguji antarmuka API dari perspektif pengguna eksternal. Pada penelitian ini, Black Box Testing digunakan untuk memvalidasi 18 skenario fungsional pada endpoint REST API modul RBAC E-Portal UIKA.
